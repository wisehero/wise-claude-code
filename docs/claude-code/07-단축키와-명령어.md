>
> Claude Code의 키보드 단축키, 슬래시 명령어, Vim 모드를 빠르게 참조할 수 있는 레퍼런스다.

## 핵심 단축키

인터랙티브 세션(대화형 세션)에서 사용할 수 있는 키보드 단축키 전체 목록이다. 외울 필요는 없다. 뒤에서 매일 쓸 것들만 따로 추려 놓았다.

| 단축키 | 동작 |
|---|---|
| `Ctrl+C` | 입력 중인 텍스트 취소 또는 응답 생성 중단 |
| `Ctrl+D` | 세션 종료 (EOF 신호 전송) |
| `Ctrl+L` | 화면 초기화 (대화 내용은 유지됨) |
| `Ctrl+O` | 상세 로그(verbose log) 토글 — 도구 호출 내역 확인 |
| `Ctrl+R` | 이전 명령어 히스토리(history) 검색 |
| `Ctrl+G` | 외부 텍스트 에디터(편집기) 열기 |
| `Ctrl+X` `Ctrl+E` | 외부 텍스트 에디터 열기 (대체 바인딩) |
| `Ctrl+B` | 백그라운드(background) 작업 전환 — 실행 중인 작업을 백그라운드로 보냄 |
| `Ctrl+T` | 작업 목록 토글 — 진행 중인 작업 상태 확인 |
| `Shift+Tab` | 권한 모드 순환 (default → acceptEdits → plan → auto → default) |
| `Esc` | 입력 취소 |
| `Esc` `Esc` | 리와인드(rewind)/요약 메뉴 열기 — 이전 상태로 되돌아가거나 대화 요약 |
| `Ctrl+V` | 이미지 붙여넣기 — 클립보드 이미지를 직접 대화에 첨부 |
| `Alt+P` | 모델(model) 선택 메뉴 열기 |
| `Alt+T` | 확장 사고(extended thinking) 토글 |

### Ctrl+C vs Ctrl+D

두 단축키는 역할이 다르다. `Ctrl+C`는 현재 작업(생성 중인 응답, 실행 중인 명령)을 중단하고 프롬프트로 돌아온다. 세션은 그대로 유지된다. `Ctrl+D`는 세션 자체를 종료하는 EOF(End of File, 파일 끝) 신호다. 응답을 멈추고 싶다면 `Ctrl+C`, 세션을 끝내고 싶다면 `Ctrl+D`를 쓴다.

## 멀티라인 입력

긴 프롬프트나 코드 블록을 입력할 때 줄 바꿈이 필요하다. `Enter`를 그냥 누르면 즉시 전송되므로 아래 방법 중 하나를 사용한다.

| 방법 | 설명 |
|---|---|
| `\` + `Enter` | 백슬래시 이스케이프 — 어떤 터미널에서도 동작하는 가장 범용적인 방법 |
| `Option+Enter` | macOS 기본 — 대부분의 macOS 터미널에서 지원 |
| `Shift+Enter` | 많은 터미널 에뮬레이터(터미널 프로그램)에서 지원 |
| `Ctrl+J` | 범용 개행 문자 삽입 — 터미널 설정에 관계없이 대부분 동작 |

터미널 종류에 따라 지원 여부가 다르다. 현재 환경에서 어떤 방법이 작동하는지 짧게 테스트해 두면 편하다.

## 슬래시 명령어

세션 안에서 `/`로 시작하는 명령을 입력하면 Claude를 거치지 않고 기능을 바로 실행한다. 자연어로 부탁하는 것보다 빠르고 확실하다.

### 세션 관리

| 명령어 | 설명 |
|---|---|
| `/help` | 사용 가능한 명령어 목록과 설명 표시 |
| `/clear` | 현재 대화 컨텍스트(문맥) 초기화 — 새 주제로 전환할 때 사용 |
| `/compact` | 대화를 요약해 컨텍스트 창 공간 확보 |
| `/rewind` | 지정한 시점의 대화 상태로 되돌아감 |
| `/rename` | 현재 세션 이름 변경 |
| `/login` | 계정 로그인 또는 계정 전환 |

### 설정 및 정보

| 명령어 | 설명 |
|---|---|
| `/config` | 설정 파일 보기 및 편집 |
| `/init` | 현재 프로젝트에 CLAUDE.md 파일 생성 |
| `/memory` | 자동 메모리(auto memory) 설정 토글 |
| `/hooks` | 훅(hook) 설정 보기 및 관리 |
| `/skills` | 로드된 스킬(skill) 목록 확인 |
| `/agents` | 사용 가능한 에이전트(agent) 목록 확인 |
| `/plugin` | 플러그인(plugin) 관리 |
| `/debug` | 디버그(debug) 정보 출력 — 문제 진단 시 유용 |
| `/mcp` | MCP(Model Context Protocol, 모델 컨텍스트 프로토콜) 서버 상태 확인 |

### 작업 모드

| 명령어 | 설명 |
|---|---|
| `/plan` | 계획 모드(plan mode) 전환 — Claude가 실제 변경 없이 계획만 수립 |
| `/fast` | Fast 모드 토글 — 확인 단계를 줄여 응답 속도 향상 |
| `/model` | 사용할 Claude 모델 변경 |
| `/vim` | Vim 모드(Vim mode) 활성화 |
| `/loop` | 지정한 명령을 반복 실행 |
| `/batch` | 여러 작업을 일괄 처리 |
| `/simplify` | 현재 대화를 간소화해 핵심만 남김 |

## Bash 모드

프롬프트 앞에 `!`를 붙이면 해당 입력을 Claude에게 전달하지 않고 셸(shell)에서 직접 실행한다.

```
! npm test
! git status
! ls -la src/
```

Claude에게 "npm test 실행해줘"라고 부탁하는 것과 결과는 같지만, 중간 과정이 없다. 명령이 즉시 실행되고 출력이 실시간으로 터미널에 표시된다. 실행 결과는 자동으로 대화 컨텍스트에 추가되므로 Claude가 이어서 분석할 수 있다.

### 자동완성 지원

`!` 뒤에 명령을 입력할 때 터미널 자동완성이 동작한다. 경로나 명령어 이름을 Tab으로 완성할 수 있다.

### 주요 활용 사례

| 상황 | 명령 예시 |
|---|---|
| 테스트 실행 결과 확인 후 수정 요청 | `! npm test` 실행 뒤 Claude에게 실패 원인 분석 요청 |
| 현재 git 상태 파악 | `! git status` 또는 `! git diff` |
| 빌드 결과 확인 | `! npm run build` |
| 파일 구조 탐색 | `! ls -la` 또는 `! find . -name "*.ts"` |

## Vim 모드

`/vim`으로 Vim 모드를 활성화하면 프롬프트 입력창에서 Vim 스타일의 편집 키바인딩(keybinding, 키 조합)을 사용할 수 있다. Vim에 익숙한 개발자라면 긴 프롬프트를 작성할 때 유용하다.

### 모드 전환

Vim 모드는 INSERT(삽입)와 NORMAL(일반) 두 가지 상태를 오간다.

| 키 | 동작 |
|---|---|
| `i` | NORMAL → INSERT (현재 커서 앞에서 입력) |
| `I` | NORMAL → INSERT (줄 처음에서 입력) |
| `a` | NORMAL → INSERT (현재 커서 뒤에서 입력) |
| `A` | NORMAL → INSERT (줄 끝에서 입력) |
| `o` | NORMAL → INSERT (아래에 새 줄 추가) |
| `O` | NORMAL → INSERT (위에 새 줄 추가) |
| `Esc` | INSERT → NORMAL |

### NORMAL 모드 주요 키

| 키 | 동작 |
|---|---|
| `h` / `j` / `k` / `l` | 좌 / 하 / 상 / 우 이동 |
| `w` | 다음 단어 처음으로 이동 |
| `e` | 다음 단어 끝으로 이동 |
| `b` | 이전 단어 처음으로 이동 |
| `0` | 줄 처음으로 이동 |
| `$` | 줄 끝으로 이동 |
| `dd` | 현재 줄 삭제 |
| `yy` | 현재 줄 복사(yank) |
| `p` | 커서 뒤에 붙여넣기 |
| `P` | 커서 앞에 붙여넣기 |
| `u` | 실행 취소(undo) |
| `Ctrl+R` | 다시 실행(redo) |

Vim 모드를 해제하려면 `/vim`을 다시 입력한다.

## 키바인딩 커스터마이징

기본 단축키가 맞지 않는다면 `~/.claude/keybindings.json` 파일을 직접 편집해 재정의할 수 있다.

### 기본 구조

```json
[
  {
    "key": "ctrl+s",
    "command": "submit"
  },
  {
    "key": "ctrl+k",
    "command": "clearLine"
  }
]
```

`key` 필드에 원하는 키 조합을, `command` 필드에 실행할 동작을 입력한다.

### chord 바인딩

chord(코드) 바인딩은 키를 연속으로 눌러 명령을 실행하는 방식이다. `Ctrl+K`를 먼저 누른 뒤 `Ctrl+C`를 누르는 식으로 조합한다.

```json
[
  {
    "key": "ctrl+k ctrl+c",
    "command": "toggleComment"
  }
]
```

키 조합 사이를 공백으로 구분해 작성한다. 두 번째 키를 일정 시간 내에 누르지 않으면 첫 번째 키 단독 동작으로 처리된다.

### 키바인딩 파일 생성

파일이 없다면 직접 만든다.

```bash
mkdir -p ~/.claude
touch ~/.claude/keybindings.json
```

변경 사항은 다음 세션부터 적용된다. 현재 세션에서는 반영되지 않는다.

## 핵심 정리

### 매일 쓸 단축키 Top 5

복잡한 단축키를 다 외울 필요는 없다. 이 다섯 가지만 손에 익혀도 일상적인 작업 흐름이 크게 달라진다.

| 순위 | 단축키 | 왜 자주 쓰나 |
|---|---|---|
| 1 | `Ctrl+C` | 생성이 길어지거나 방향이 잘못됐을 때 즉시 중단 |
| 2 | `Shift+Tab` | 반복 승인이 필요한 작업에서 auto 모드로 전환 |
| 3 | `Ctrl+L` | 화면이 복잡해졌을 때 깔끔하게 초기화 |
| 4 | `Esc` `Esc` | 잘못된 방향으로 흘러간 대화를 이전 시점으로 되돌리기 |
| 5 | `Ctrl+O` | 도구가 어떻게 작동하는지 상세 로그로 확인 |

### 빠른 참조 카드

```
[ 단축키 ]
Ctrl+C   생성 중단      Ctrl+D   세션 종료
Ctrl+L   화면 초기화    Ctrl+O   로그 토글
Ctrl+R   히스토리 검색  Ctrl+V   이미지 붙여넣기
Shift+Tab 권한 모드 순환  Esc+Esc  리와인드 메뉴
Alt+P   모델 선택      Alt+T   확장 사고 토글

[ 멀티라인 ]
\+Enter  범용   Option+Enter macOS
Shift+Enter 대부분의 터미널   Ctrl+J  범용

[ 슬래시 명령어 ]
/help    도움말      /clear   컨텍스트 초기화
/compact 대화 요약   /rewind  이전 시점 복원
/plan    계획 모드   /model   모델 변경
/vim     Vim 모드    /config  설정 보기
/init    CLAUDE.md 생성

[ Bash 모드 ]
! 명령어   Claude를 거치지 않고 셸에서 직접 실행
```
